# Total Collision — сервер связи

Игроки подключаются к этому серверу вместо прямого соединения друг с другом.
Работает через обычный HTTPS-порт, поэтому проходит через VPN и жёсткие сети.

Файлы: `server.js` (комнаты и связь), `accounts.js` (аккаунты, друзья, личные сообщения), `package.json`.

Запуск: `npm install`, затем `node server.js` (порт берётся из переменной PORT).
Проверка: открыть адрес сервера в браузере, должна быть надпись «Total Collision server OK».

## Где хранятся аккаунты

Папка берётся из переменной окружения `DATA_DIR`. Если её нет, но существует доступная для записи папка `/data` (постоянный диск Render), берётся она.
Иначе данные лежат в папке `data` рядом с сервером (на бесплатном хостинге она стирается при каждом перезапуске).
В папке создаются `users.json`, `tokens.json` и `dm/` (личные переписки).

## Что умеет

- Комнаты по коду; если хост обновил страницу, комната ждёт его 60 секунд и возвращает на то же место.
- Регистрация и вход по нику и паролю (пароль хранится только в виде хеша scrypt), постоянный вход по токену.
- Поиск игроков по нику (по началу) и по числовому ID, заявки в друзья, статус «в сети».
- Личные сообщения между друзьями с историей и счётчиком непрочитанных.
